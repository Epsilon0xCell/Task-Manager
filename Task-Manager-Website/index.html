Task-Manager

A single file interactive Python program, standard library only. Tasks are kept in a list in memory for the session only and nothing is written to disk. Start it with python3 task-manager.py.

Open the repo Behaviour and tests

1

1. ADD

Asks for a description and whole days until due. Blank descriptions, text day counts, and negative days are refused, each with an explanation, and the task is not added.

2

2. COMPLETE

Matches a task by its exact case sensitive name. A match reports Marked completed; no match says no task with that name was found.

3

3. PRINT

Lists every task with its number, its status as 1 for completed or 0 for not, and its days remaining.

4

4. REMOVE

Shows the list before and after as every completed task is taken out. Only uncompleted tasks remain.

5

5. RANDOM

Prints one task picked at random, or a short no tasks message when the list is empty.

6

6. NEXT

Prints the task or tasks with the fewest days left, comparing days as numbers, so 2 days is chosen ahead of 100.

7

7. QUIT

Prints Bye! Bye! and leaves. The same farewell answers Ctrl-C or closed input at the menu or any sub-prompt.

The landing list

Every session opens with two tasks:

walk dog: due in 2 days, already completed (status 1).

Eat tree: due in 30 days, not completed (status 0).

Quitting erases the list, because nothing is saved to disk.

Behaviour and testing

Bad menu entries, from text to 3.5 to 99, bring back the request for a number from 1 to 7 with no traceback. The test suite runs with python3 -m unittest across 19 tests covering the task class, with its task_due and day_passed methods, and scripted menu runs.

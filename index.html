Task-Manager

A minimal interactive task manager in Python, in a single file, using only the standard library. Tasks live in an in-memory list for the duration of the session; nothing is saved to disk, so the list resets when you quit, exactly like a planner page that is finished and closed at the end of the day.

Open the repo The tests

Run it

python3 task-manager.py

The program starts with two built-in example tasks already on the page: walk dog, due in 2 days and marked completed, and Eat tree, due in 30 days and not completed. Then the menu appears.

The menu

1. ADDadd a task, with a description and whole days until it is due
2. COMPLETEmark a task completed by its exact, case-sensitive name
3. PRINTlist all tasks with their status and days remaining
4. REMOVEremove every completed task from the list
5. RANDOMprint one task chosen at random
6. NEXTprint the task with the fewest days remaining
7. QUITexit

Behaviour, checked line by line

  • The menu accepts only a whole number from 1 to 7. Anything else prints Please enter a number from 1 to 7. and shows the menu again, with no traceback.
  • Closing the input (EOF, for example Ctrl-D) or pressing Ctrl-C at the menu or at any sub-prompt prints Bye! Bye! and exits with status 0.
  • ADD rejects a non-numeric days value, a negative days value, and a blank description, each with an explanation, and does not add the task.
  • COMPLETE reports what it did, and REMOVE really removes: completed tasks are gone from a following PRINT, which is shown before and after.
  • NEXT compares days as numbers, so a task due in 2 days is chosen ahead of one due in 100 days. NEXT and RANDOM on an empty list print a short no-tasks message instead of crashing.

The tests

python3 -m unittest

19 tests: the task class on its own (string fields stored as ints, due checks, day_passed, removal mutating the caller's list) and scripted menu runs (add, complete, remove, next, quit, bad input, EOF, and a simulated Ctrl-C).
